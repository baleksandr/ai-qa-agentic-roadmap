# Еталон інтерактивних схем (вкладка «Агент: загальний цикл»)

Орієнтир для наступних діаграм у курсі. **Не змінювати еталонну вкладку** без окремого запиту — копіювати патерни.

## Маршрут і навігація

- Один **зрозумілий основний маршрут** (happy path) з лічильником переходів; бічні гілки й legacy — поза основною стрічкою або в мінікартках зв’язків.
- Кроки симуляції синхронізовані з видимими переходами; пояснення **справа** (панель кроку / вузла / переходу), не дублювати той самий текст на картці й у панелі.

## Картки вузлів

- **Англійська назва** — акцентний колір, напівжирний; **український переклад** — окремий рядок; одне коротке речення про дію або вміст.
- Без фонетичної вимови українськими літерами.
- Висота картки з урахуванням переносів; текст не виходить за рамку.

## Інтерактивні картки (напис дії)

- Клік **підсвічує зв’язок** на схемі → «Показати зв’язок →» / після вибору «Зв’язок показано ✓».
- Клік **відкриває пояснення** у панелі → «Відкрити пояснення →» / «Пояснення відкрито ✓» (вузли полотна, RAG/MCP).
- Перехід на урок → «Перейти до уроку ↗».
- Напис дії — **окремий нижній рядок**; звичайні інформаційні блоки (секції «Звідки», «Що передається») без вигляду кнопки.
- Спільні класи: `.arch-interactive-card-action`, `.arch-interactive-card`, `.arch-interactive-panel-card`; `ArchInteractiveActionLabel`.

## Стан вибору та опції

- **Помітний збережений вибір** вузла (`is-picked` / `aria-pressed`), окремо — підсвітка кінців активного переходу.
- **RAG / MCP** — окремі візуальні акценти (колір рамки, чипи); пояснення «Що таке RAG і MCP?» — одна панель, без дубля в DOM.

## Стрілки та полотно

- З’єднання **від краю до краю** картки (handles + маршрутизація); короткі **українські** підписи на стрілках.
- **Pan / zoom**, кнопка **«Вмістити»** (fit overview), обмеження min/max zoom.

## Реалізація (орієнтири в коді)

| Що | Де |
|----|-----|
| Схема агента, кроки | `src/data/architecture/schema-agent.ts` |
| Вертикальна sim + React Flow | `ArchitectureVerticalSimDiagram.tsx`, `agentCycleReactFlow.ts`, `agentCycleDiagramLayout.ts` |
| Стилі | `src/App.css` (`.arch-vsim-*`) |

Бічна панель **«Увесь маршрут»** на карті — інший, але суміжний стандарт: `route-topic-side-panels.ts`, `RouteTopicSidePanelBody.tsx`, `review-mode.css` (`.route-side-panel-*`).

**Перевірка в браузері (схема агента):** `npm run preview -- --port 4173` і `node scripts/route-panel-browser-check.mjs`. Скрипт відкриває `#/agent-architecture?tab=agent`, не головну карту. `npm run build` і `node scripts/verify-agent-interactive-card-actions.mjs` — лише статичні перевірки, не замінюють Playwright.
