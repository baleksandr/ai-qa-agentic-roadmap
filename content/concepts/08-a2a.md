## Review Mode

**Проблема:** агенти на різних сервісах мають обмінюватися задачами без спільного monolith harness.

**Ідея A2A (agent-to-agent):** **протокол повідомлень** між агентами (delegate task, status, result) — код транспорту + контракт, не LLM «телепатія».

**Для QA:** security меж агентів, correlation id через chain.
